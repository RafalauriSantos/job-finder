# Java — Trilha de Aprendizado do Job Finder

## Já praticado

- modelagem com `record`;
- contratos com interfaces;
- enums para estados de domínio;
- imutabilidade de coleções;
- testes JUnit;
- separação entre regra de negócio e infraestrutura.

## Próximos conceitos

1. Maven e ciclo de build;
2. Spring Boot e injeção de dependências;
3. PostgreSQL e SQL;
4. Flyway e migrations;
5. HTTP e API REST;
6. persistência com Spring Data;
7. integração com Hermes;
8. IA aplicada com fallback e auditoria.

## Método de estudo

Cada módulo deve conectar teoria, implementação, teste e uma explicação própria no Obsidian. O objetivo é aprender Java construindo um produto real, não apenas completar exercícios isolados.
