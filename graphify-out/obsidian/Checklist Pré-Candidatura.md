# Checklist Pré-Candidatura

Usar antes de enviar currículo, formulário, e-mail ou candidatura assistida.

- [ ] Nome da empresa conferido.
- [ ] Título exato da vaga conferido.
- [ ] Requisitos principais revisados.
- [ ] Localização e modalidade conferidas.
- [ ] Senioridade conferida.
- [ ] Currículo correto anexado.
- [ ] Links do portfólio funcionando.
- [ ] E-mail do destinatário conferido.
- [ ] Assunto revisado.
- [ ] Mensagem revisada sem placeholders ou nomes de outra empresa.
- [ ] Data e prazo conferidos.
- [ ] Envio registrado no acompanhamento de candidaturas.

Nenhuma candidatura deve ser enviada automaticamente sem aprovação explícita do Rafael.
